Percentage change calculator

Percentage change compares a new value with an original one. Enter the starting and finishing values to see how far they moved in percent terms.

Formula

% change = (to − from) / |from| × 100

Worked example

  1. From 200 to 250: difference = 250 − 200 = 50.
  2. Divide by the starting value: 50 / 200 = 0.25.
  3. 0.25 × 100 = 25%, so the value increased by 25%.

Assumptions and limitations

  • The denominator is the absolute value of the starting figure, so the sign of the change is intuitive even when the base is negative.
  • The change is a simple two-point comparison — it ignores anything happening between the two values.

Frequently asked questions

Why does a rise then a fall not cancel out?

Each percentage is measured against a different base, so moving 100 up 50% then down 50% ends at 75, not 100.

What if the starting value is negative?

Using |from| avoids a sign flip. Rising from −100 to −50 is reported as +50%, a genuine increase.

Can the change be more than 100%?

Yes. Doubling a value is a 100% increase; tripling it is a 200% increase.
