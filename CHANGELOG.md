# Changelog

All notable changes to the PARCHXA toolkit are documented here.
The project is a zero-build static site; "releases" are just commits to `main`.

## [2.0.1] — 2026-10-14

### Added

- **Real social preview image:** `icons/og.png` (1200×630) rendered by the new dependency-free
  `tools/og-image.mjs` (built-in 5×7 bitmap font + a minimal PNG encoder over `zlib`). Replaces the
  SVG placeholder, which most crawlers ignore.
- **`tools/apply-og.mjs`:** idempotent codemod that adds `og:image` / `twitter:image` to every page
  and upgrades `twitter:card` to `summary_large_image`. Runs in `--check` mode in CI via
  `tools/verify.mjs`.

### Changed

- `package.json`, `tools/og-image.mjs` and the toolchain docs now cover four generators/verifiers.
- `tools/verify.mjs` also validates OG-image tags and that each referenced image file exists.
- Service worker cache bumped to `parchxa-v5` (caches `icons/og.png`).

### Removed

- `icons/og.svg` (superseded by the generated PNG).

## [2.0.0] — 2026-10-14

A large depth-and-quality pass: a much bigger math/risk engine, a new advanced-math tool, deeper
finance tools, a programmatic-SEO page family, a proper Node toolchain, and site-wide security hardening.

### Added

- **Advanced math tool (`math.html`, `js/math.js`):** scientific calculator, descriptive statistics
  (mean/median/mode/variance/std-dev/skew/kurtosis/quartiles), correlation, linear and polynomial
  regression, one-sample/Welch/paired t-tests, chi-square goodness-of-fit, an SVG function plotter
  with numeric derivative and integral, 2×2–n×n matrix arithmetic (add/sub/mul/transpose/det/inverse)
  and a base converter.
- **Extended quant engine (`js/quant.js`):** inferential statistics (t-tests, chi-square, incomplete
  beta, student-t/normal CDFs), risk metrics (max drawdown, Sharpe/Sortino/Calmar, VaR, risk of ruin),
  finance helpers (NPV/IRR, loan payment, CAGR, DCA vs lump sum) and more indicators (MACD, Bollinger,
  Keltner, Donchian, OBV, MFI, ADX, Supertrend, Ichimoku, pivots, Fibonacci).
- **Money planner upgrades (`money.html`):** fixed-rate loan amortization with a yearly schedule,
  VAT/sales-tax add-or-extract, margin vs markup, and break-even volume.
- **Programmatic-SEO profit pages:** `profit.html` hub plus `profit-<coin>.html` for 12 major coins,
  each with unique copy, FAQ, JSON-LD, a what-if table and a live share card. Generated by
  `tools/generate.mjs`, which also rebuilds `sitemap.xml`.
- **Command palette (`js/command-palette.js`):** ⌘K / Ctrl-K (or `/`) to search every tool and
  common action.
- **Share cards (`js/sharecard.js`):** branded PNGs rendered on `<canvas>` and shared via the Web
  Share API, with per-page live numbers.
- **Local-first analytics (`js/analytics.js`):** ring-buffered events, Web Vitals and scroll depth,
  forwarded to Plausible/Umami only after consent.
- **Input hardening (`js/sanitize.js`)** applied across the codebase, plus a site-wide
  `Content-Security-Policy` meta on every page (`tools/csp.mjs`, `tools/apply-head.mjs`).
- **Toolchain:** `tools/serve.mjs` (dev server), `tools/verify.mjs` (one-shot CI check),
  `package.json`, Dependabot config and a rewritten `validate.yml`.
- **PWA:** richer manifest (shortcuts, categories, display overrides), v4 service worker with an
  offline fallback page and `.nojekyll`.

### Changed

- `js/site.js` rebuilt around a single source of truth (`js/nav.js`) and now renders navigation,
  compliance, monetization, consent, share buttons, analytics and the PWA registration.
- `js/affiliates.js`, `js/config.js`, `js/products.js` turned into typed, documented registries that
  render nothing until configured.
- `js/advanced.js` expression engine now supports variable lookup (used by the plotter).
- Service worker strategy: network-first HTML with an offline fallback, cache-first static assets.

### Fixed

- Removed an HTML-escape call that was applied to canvas text on share cards.
- Clarified and documented that all monetization and analytics stay off until configured.

### Security

- Added a `Content-Security-Policy` meta (with `object-src 'none'`, `base-uri 'self'`,
  `form-action 'self'`, restrictive `connect-src`) and `referrer` policy to all pages.
- All URL parameters and stored values are validated via `js/sanitize.js` before use.

## [1.0.0] — prior

Initial public toolkit: invoice and quotation builders, freelance calculators, money planner,
trading-risk suite, student toolkit, live chart & backtester, 56 currency converters, 11
hourly-to-salary pages, and a memorial page generator.
