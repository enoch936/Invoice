Forex pip value calculator

A pip value tells you what each price step is worth in your own currency. Enter the pip size, contract size and lots to convert a move into money.

Estimates only. Results depend on the inputs you provide and the assumptions listed below. This is an educational tool, not financial, tax or investment advice.

Formula

Pip value = pip size × contract size × lots × quote-to-account rate

Worked example

  1. Standard lot: pip size 0.0001, contract size 100,000, 1 lot, quote-to-account rate 1.
  2. Value per pip = 0.0001 × 100,000 × 1 × 1 = $10.00.
  3. With 0.5 lots and a rate of 1.25: 0.0001 × 100,000 × 0.5 × 1.25 = $6.25 per pip.

Assumptions and limitations

  • Contract size is a fixed number of base-currency units; mini and micro lots are modelled by entering fractional lots.
  • The quote-to-account rate is treated as constant, but real exchange rates move with the market.
  • Spreads, commissions, swap/funding and slippage are excluded, and a pip is assumed to be worth the same at entry and exit.

Frequently asked questions

What exactly is a pip?

A pip is the conventional smallest price move for a pair — 0.0001 for most pairs and 0.01 for JPY pairs. On five-digit brokers a fractional pip (point) is one tenth of that.

Why does pip value change between pairs?

The pip is a move in the quote currency. If your account is in a different currency, the value must be converted at the current rate, so it changes with the market.

Does contract size matter?

Yes. Pip value is proportional to position size, so a micro lot (1,000 units) is worth one hundredth of a standard lot (100,000 units).
